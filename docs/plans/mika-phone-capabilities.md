## 已实现的合同

### 执行可靠性

`UiExecutionVerification` 为输入结果与画面稳定状态提供明确结论。读不回输入或无法取得
稳定证据时保留未知状态；API 返回成功不再单独作为输入已匹配的证据。不会因为未知或超时
自动重放写操作。稳定检测使用现有无障碍观察，不新增静默截图、静默 OCR 或远端请求。

### 组合工具

`ui_collect`、`ui_find`、`ui_set_wheel` 在 `ToolExecutionBoundary` 内编排，使用原有
观察与动作工具，每个子请求重新检查授权、schema、前台包和取消状态。组合不是批准一次
即可绕过子步骤确认的批处理；无法获得有效授权时停止。每次组合最多五个写子步骤，
总执行时间有 30 秒上限。采集/查找页面上限为五页。

结果标为 `LocalOnly`，只供本地规划与合成。采集保留部分结果、截断与停止原因；找到目标
不自动点击。滚轮必须通过实际读回确认目标，不能仅凭推算中间值报告成功。遇到切包、
不可读页面、危险控件拒绝、无进展、预算耗尽或取消时停止，不能以备用手势绕过门禁。
采集的 `Succeeded` 仅代表取得可用片段，`completed=false` / `partial=true` 仍表示未证明
整个列表已读完。当前仅合并相邻页首尾重叠；固定页眉/页脚可能使重复片段保留，不承诺
动态列表完整去重。滚轮目前仅支持可识别的 NumberPicker，不泛化到任意自绘控件。

### 受控路线复用

`VerifiedPhoneRoutes` 与 `VerifiedPhoneRouteReplanner` 不操作设备，只提出下一条正常
`ToolRequest`，由现有循环、执行边界和动作门禁决定是否执行。每一步仍有确认 draft，
历史授权不继承。

- 只学习确定性搜索验证成功、且输入读回为匹配的短路线；模型回答、`finish` 或通用
  `Succeeded` 不足以触发学习。
- 以同一会话和完整原话的带随机盐摘要匹配，不泛化改写要求或任意新参数。参数从当前
  用户原话区间取值，不保存原始输入、屏幕文字、截图或凭据。
- 只接受完整、未截断、无敏感标记且新鲜的本地无障碍观察。每步核对包名、页面摘要和
  唯一目标；不保留旧坐标或旧节点编号。
- 出错、切换 App、目标歧义、请求变更或前后页面不连续时放弃本轮回放。连续两次路线
  失配停用该路线；动作结果未返回时不再提出写操作。
- 最多五步、最多 32 条内存路线；进程退出即消失。历史清理/所有者释放需清除路线实例。
  本批不提供跨进程持久化，不以“学习完成”承诺后续任务必然成功。

### 后台屏幕实验

`device/background/BackgroundPhoneHelper.kt` 与 `BackgroundPhoneSession.kt` 是显式启用的
实验后端；正常使用仍以现有前台无障碍路径为默认。

- 仅对可调试 APK，经用户已经授权的 ADB 启动 helper；不自动开启调试、不解锁手机、
  不授予系统设置权限。凭据有效期为 15 分钟。
- helper 基础能力要求 Android 12+；启动独立焦点后台应用要求 Android 14+，还取决于
  系统是否授予所需显示能力。不支持时应明确失败，不声称所有 OEM 均可后台无干扰操作。
- 只提供本实验需要的窄显示/控制接口，不能向模型暴露通用 shell 执行或解锁能力。
  点击、输入等动作仍经过既有动作门禁；权限和 session 失效后不能继续执行旧操作。
- helper 只监听 `127.0.0.1` 随机端口。ADB 将短期凭据写入 App 私有文件，连接成功后
  消耗该文件；双方以 HMAC 随机挑战证明持有密钥，TCP 中不发送密钥。每帧认证绑定
  会话随机数、方向和递增序号，拒绝篡改与重放；握手有五秒绝对期限。
- debug 控制入口可显式选择后续任务使用后台屏幕。运行在创建时冻结选择，工具执行和
  结果观察沿用同一绑定；关闭、过期或进程恢复后不会改用主屏。只持久化后台运行 ID
  标记，所有者释放保留标记，确实终态才删除；不保存任务内容或恢复旧凭据。
- 后台作用域禁用远程视觉和主屏 MediaProjection OCR，直到独立显示截图的授权、
  来源和外发边界有独立实现与证据。当前不得将主屏截图误当作后台目标画面上传。

## 验证状态与交付边界

集成生产代码通过 2687 项 JVM 测试；API 36 已实际通过输入读回、稳定等待、片段采集、
只查找不点击、拒绝未授权滚动和后台默认禁用六项测试。后台 debug 路径已验证独立建屏、
启动 Settings、观察、受控点击及页面变化、截图、跨 30 秒空闲、选择后返回聊天与显式停止。
这不证明所有真实 App/OEM 兼容，也不代表普通聊天模型任务已端到端通过。具体命令、APK
版本和证据边界见 [验证报告](../validation_report.md#2026-11-04--mika-phone-capability-integration)，
不能沿用上游测试文件存在或演示视频作为栖知通过证据。

以下仍需按当前 APK 在设备上验证：WebView 输入事件、中文及多行输入、动态长列表去重、
实际 NumberPicker 吸附、授权/取消中断、OEM 后台显示与焦点、主屏用户介入、锁屏、
helper 到期及异常退出。Android 12/13 的受限行为与 Android 14+ 的独立焦点行为必须
分别记录。未执行的设备用例记 `pending`，不能从 JVM 通过推断。
